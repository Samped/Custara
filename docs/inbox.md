# Inbox

Inbox is `/app/inbox`. Open it from **Go to → Work → Inbox**.

Inbox is the full invoice list, newest first. Each row shows the vendor, amount, due date, and status. Open a row to see extraction, risks, and the pay card.

## Upload

Admins and payers can analyze a file from here. The dialog accepts JSON, TXT, PDF, CSV, or TSV. **CSV template** downloads the column header row for a bulk file.

After a successful upload the new bill is in the list. A missing file or a rejected file shows the error on this page.

## Mailbox

The mailbox panel shows the workspace ingest address. Forward supplier mail there after the mailbox is connected.

**Configure** opens Connectors, where the IMAP host, user, and app password are saved. **Sync now** appears when that mailbox is already connected and pulls new messages immediately.
