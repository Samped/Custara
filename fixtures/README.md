## Local pay-ready invoices (gitignored)

For manual upload + agent-pay drills, generate fresh files that are **never pushed**:

```bash
npm run fixtures:pay-ready
```

Output (ignored via `.gitignore` → `test-fixtures/`):

| File | Path |
|------|------|
| Agent / Arc USDC | `test-fixtures/pay-ready/agent-pay-usdc.pdf` (+ `.json`) |
| Nigeria export NGN | `test-fixtures/pay-ready/export-pay-ngn.pdf` (+ `.json`) |

Each run mints a unique invoice number suffix so re-upload avoids duplicate holds.

### Upload → agent pay checklist

1. `npm run fixtures:pay-ready`
2. Hard-refresh the app; upload `test-fixtures/pay-ready/agent-pay-usdc.pdf` (or `.json`)
3. If `new_vendor`: **Verify vendor & clear risk**
4. On the invoice: **Confirm destination & unlock pay** (address `0xd9792bf937d9673ab08c452fe55ec4e26632be54`); sync agent balance in Wallets if needed
5. Approve if still pending; **Initiate payment** (Redis + `npm run worker`)
6. Expect intent + `AgentTask arc_transfer` on Wallets / Payments

Seeded Lagos org already has Arc Softgoods / Northern Haulage. On a JIT org (e.g. LOOP), first upload creates the vendor — verify + allowlist still apply.
