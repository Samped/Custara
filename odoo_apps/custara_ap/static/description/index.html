Setup

Install, key, send.

  1. Install Custara AP on Odoo 18 (self-hosted or Odoo.sh).
  2. Settings → Accounting → Custara AP: https://custara.xyz and a Partner API key from Developers.
  3. Open a vendor bill → Send to Custara, or post the bill and wait for sync.
  4. Approve and pay in Custara. The payment writes back onto that bill.

Odoo Online can skip the module and use Custara → Connectors. Demos only: testnet.custara.xyz
