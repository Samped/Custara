Custara AP

Approvals and Arc testnet USDC settlement. Odoo stays the ledger.

Custara is the accounts-payable control plane for Odoo shops. Reviewers approve in Custara. Payments write back to the same vendor bill. Settlement is Arc testnet USDC, not mainnet, until a later compliance gate.

Use this module on self-hosted Odoo or list it on odoo.com/apps. Odoo Online can keep using the JSON-RPC API key from Custara → Connectors without installing the module.

  • Send vendor bills and credits to Custara Inbox
  • Keep Odoo as the book of record
  • Label every remittance as Arc testnet USDC
