Custara AP

Approvals and Arc mainnet USDC settlement. Odoo stays the ledger.

Custara is the accounts-payable control plane for Odoo shops. Reviewers approve in Custara. Payments write back to the same vendor bill. Settlement is Arc mainnet USDC on custara.xyz. Use testnet.custara.xyz only for demos.

Use this module on self-hosted Odoo or Odoo.sh. Odoo Online can keep using the JSON-RPC API key from Custara → Connectors without installing the module.

  • Send vendor bills and credits to Custara Inbox
  • Keep Odoo as the book of record
  • Settle approved bills in Arc mainnet USDC via Circle
  • Dual control, destination allowlist, and hash-chained audit in Custara

Setup

  1. Install Custara AP and update the Apps list.
  2. Settings → Accounting → Custara AP: set API URL to https://custara.xyz and paste a Custara Partner API key.
  3. Open a vendor bill and click Send to Custara (or post the bill to auto-push).
  4. Approve and pay in Custara. The payment writes back onto the same Odoo bill.
